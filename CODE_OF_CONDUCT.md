# Code of conduct

Praecepta follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and constructive, assume good intent, and keep discussions about the work.
Harassment and personal attacks are not tolerated in issues, pull requests or any other project
space.

## Reporting
Report unacceptable behaviour privately to the maintainer,
[@brunopacheco1](https://github.com/brunopacheco1), using the contact details on their GitHub profile.
Reports are handled confidentially. The maintainer may remove, edit or reject comments, commits,
code and issues that do not follow this code of conduct, and may ban contributors who repeatedly
or seriously break it, following the Covenant's enforcement guidelines.
