Gradle plugin · io.github.brunopacheco1.praecepta · Gradle 8.5+ · Java 21+

Compile DMN, Excel and CSV decision tables when you build.

The Praecepta Gradle plugin reads your decision tables, validates them (gaps, overlapping and unreachable rules, values outside the declared lists), fails the build on errors, and generates typed Java: an input record, an output record and a class that evaluates the table with the Praecepta engine. It does for Gradle what the Maven plugin does, with the same settings and the same generated files.

Apply the plugin

The plugin is on the Gradle Plugin Portal, where Gradle looks for plugins by default. The generated classes need the engine at runtime, and nothing else: the plugin's own dependencies (Apache POI for Excel) stay in the build.

Then ./gradlew build: the plugin validates shipping.dmn, writes it as a resource, and generates ShippingInput, ShippingOutput and Shipping in com.acme.pricing, compiled with the rest of main.

Configure the tables

A DMN file needs only its source. An Excel workbook (first sheet) or a semicolon-separated CSV file has a header row that names the columns and one rule per row, with cells in DMN's syntax (>= 18, "PT","ES", [1..10], -); declare its hit policy and its input and output columns in the build:

The praecepta extension
SettingMeaning
packageNamePackage of the generated classes and DMN resources (required; empty for the default package).
failOnFail the build when validation finds issues at least this severe: ERROR (default), WARNING or NONE. A table that cannot be read fails the build whatever this says. Every finding is logged.
fileHeaderText put first in every generated source as // comments, such as your project's SPDX lines. None by default: generated code belongs to your project.
skipWrite nothing. Defaults to the Gradle property praecepta.skip (-Ppraecepta.skip=true).
tablesThe tables to compile, each registered under a name of its own (used in Gradle's messages).
Each table
SettingMeaning
sourceThe .dmn, .xlsx or .csv file (required).
classNameName of the generated class; by default the DMN decision's name or the file name (discount.xlsx gives Discount).
decisionDMN only: which decision table to read, when the file has several.
hitPolicyExcel and CSV only (required there): UNIQUE, ANY, PRIORITY, FIRST, OUTPUT_ORDER, RULE_ORDER or COLLECT.
aggregationExcel and CSV only: SUM, MIN, MAX or COUNT, for a COLLECT table with one NUMBER output.
inputs, outputsExcel and CSV only: the columns, in order, each declared with column("name") and configured as below.
Each column
SettingMeaning
typeSTRING (default), NUMBER, DATE, BOOLEAN, TIME, DATE_TIME, DAY_TIME_DURATION or YEAR_MONTH_DURATION.
allowedValuesInputs: the DMN input value list, as unary tests ("PT","ES" or [0..120]). A string column with one becomes an enum in the input record, and validation reports values outside it.
listInputs: the column holds lists of its type, such as a customer's nationalities; a cell then matches when some element passes one of its tests.
priorityOutputs: the DMN output value list, highest priority first, for PRIORITY and OUTPUT_ORDER.

The settings are the Maven plugin's, as Gradle properties. One name differs: name is the name a table is registered under, as in every Gradle container, so the class is named by className (the Maven plugin's <name>).

Use the generated classes

  • Single-hit tables and aggregations return an Optional; multi-hit tables return a List. When no rule matches they are empty, unless the table declares default output values: then they hold the default output.
  • Numbers are BigDecimal and dates LocalDate. Times and date-times are LocalTime and LocalDateTime, or OffsetTime and ZonedDateTime when every value written for the column has a time zone; a column whose values name zone ids is the engine's ZonedTime. A string column with a value list is an enum, and a list column a java.util.List.
  • The DMN resource is written next to the classes, so the table ships in your jar as DMN.
  • From 0.7.0, a DMN file whose decisions require other decisions (a decision requirement graph of decision tables and literal expressions) compiles to a class named after the model, which holds the graph, and a class per decision with an input record of the input data it needs; the graph's cycles, missing requirements and type mismatches fail the build at failOn (details).

The generatePraecepta task

  • Writes the classes to build/generated/sources/praecepta/java/main and the DMN resources to build/generated/resources/praecepta/main. Both belong to the main source set, so compileJava and processResources run the task first.
  • Cacheable: its inputs are the table files (by name and content) and the settings, so an unchanged build takes it from the build cache. It works with the configuration cache.
  • Empties both directories on each run, so a table you remove leaves no class behind.
  • Runs on Gradle 8.5 and later; CI builds a sample project with Gradle 8.5, the last 8.x and the current 9.x, on Java 21 and later.
