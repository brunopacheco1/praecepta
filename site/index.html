Open source · Apache-2.0 · Java 21+

DMN decision tables for Java, answered in a fraction of a microsecond.

Praecepta (Latin for “rules”, said pry-KEP-ta) evaluates DMN decision tables with strict DMN hit policies. Write tables in a modeller, Excel, CSV or code; validate them when you build; evaluate them with a small engine that has no dependencies.

Benchmarks

  • 0.19 µsper decision on a real 119-rule table
  • 20–2,000×faster than Camunda 8 and Drools, from 10 to 10,000 rules
  • 5 MBof heap for 10,000 rules, against 108–133 MB
  • 76 msfrom a fresh JVM to the first decision, against 379–469 ms

JMH on an Apple M2 Pro, every engine reading the same DMN file and checked to give the same answers. Every log and raw result is published, including where Praecepta is slower: building large FIRST and PRIORITY tables (#29).

What it does

Strict DMN hit policies

UNIQUE, ANY, PRIORITY, FIRST, OUTPUT ORDER, RULE ORDER, and COLLECT with SUM, MIN and MAX.

FEEL cells

Lists, not(...), comparisons, intervals and null on string, number and date columns, with optional input value lists.

Validation when you build

Overlapping rules, conflicting outputs, rules that can never fire, and gaps: inputs no rule covers, with an example.

DMN in, DMN out

Reads DMN 1.1 to 1.5, including files from Camunda Modeler, and writes DMN 1.3 that Camunda and Drools evaluate the same way.

A Maven plugin

Compiles Excel, CSV and DMN tables at build time into typed input and output records, so your application ships only the engine.

Small and safe to share

No runtime dependencies, a JPMS module, and immutable engines that any number of threads can share.

How it works

Every rule gets one bit. For every column, each value the rules can tell apart gets a mask: the rules that accept it. Numbers and dates are split at the boundaries the rules mention, and a binary search finds the interval.

Evaluating an input looks up one mask per column and ANDs them. A 64-bit AND checks 64 rules at once, and the hit policy reads the result: FIRST is the lowest set bit, a single CPU instruction. Memory grows with columns × values × rules, never with their product.

What it is not

Praecepta does one thing: single DMN decision tables, fast. Use Camunda or Drools when you need:

  • Full FEEL: functions, arithmetic, contexts, and tests across several columns, such as income > 2 * rent. Praecepta cells are FEEL simple unary tests on one column.
  • Decision requirement graphs: decisions feeding other decisions, business knowledge models and boxed expressions.
  • More column types: boolean, time and date-time columns are planned.
  • A process engine, a modeller or a decision service around the tables.
